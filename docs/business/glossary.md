## Process terms

| Term | Meaning |
|---|---|
| Epic | A large capability made of several user stories. |
| User story | A small piece of value from a user's point of view: "As a …, I want …, so that …". |
| Task | A technical step needed to deliver a story. |
| Milestone | A group of work delivered together (e.g. "MVP"). |
| Story points | A relative measure of effort and uncertainty (1, 2, 3, 5, 8), not hours. |
| Definition of Ready | The checklist an item must pass before work starts. See [DoR](../process/definition-of-ready.md). |
| Definition of Done | The checklist an item must pass to be considered finished. See [DoD](../process/definition-of-done.md). |
| ADR | Architecture Decision Record: a short note explaining an important technical decision and why it was made. |
